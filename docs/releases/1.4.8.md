# GlassDesk Plus 1.4.8

移除日历小组件。

## 改动

- 设置 → 小组件 里不再有「日历」，Dock 上也不再出现日历图标
- 小组件从 8 个减为 **7 个**：时钟 / 日期 / 系统监控 / 天气 / 音频 / 备忘录 / 待办
- 旧配置里的 `"kind": "Calendar"` 条目会在加载时被丢弃，之后保存即从文件里消失
- `WidgetKind.Calendar` 枚举值**保留**但不再使用：`settings.json` 用字符串存枚举，
  直接删掉会让旧配置反序列化失败、整份设置被判损坏而回退

## 验证

`--widgets-default` 扩到 12 项，新增两条：

```
设置界面不再有日历开关        -> 已移除
日历条目在规范化后被丢弃      -> 可用类型 7 个、规范化后 7 个
```

## 升级说明

覆盖安装即可。旧的日历设置不会报错，也不需要手工清 `settings.json`。
