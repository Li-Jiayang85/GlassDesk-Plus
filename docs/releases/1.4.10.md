# GlassDesk Plus 1.4.10

修三个层叠相关的问题：Dock 被遮挡时的隐藏逻辑、窗口打开时 Dock 压在上面、桌面歌词把 Dock 挤没。

## 1. Dock 不再置顶，窗口打开时它待在窗口下面

**原因**：Dock 窗口带 `Topmost`，任何普通窗口都压不住它，最大化时直接"跳"在窗口内容上。

**处理**：Dock 改为普通层窗口（`Topmost="False"`）。

- 打开窗口并把窗口移到 Dock 上：窗口盖住 Dock，Dock 仍在但位于其下方
- 桌面可见时 Dock 正常显示（桌面在最底层，不受影响）
- 全屏/最大化仍走收起逻辑，不受影响
- 启动台内部拖拽期间 Dock 需要临时提到置顶，拖拽结束会显式放回普通层
  （新增 `WindowStyles.SendToNormalBand`），不会留下"一直是置顶"的残留

**实测**：

```
普通窗口压住    Dock 可见，区域亮度 125 -> 47（窗口画在上面）
最大化          Dock 立即收起，3 秒内保持隐藏
还原            约 700ms 后恢复
```

## 2. 被遮挡时的隐藏逻辑：从"碰到就藏"改成"全盖住才藏"

**原因**：`ForegroundCoverage.IsCovered` 判定的是**前台窗口与 Dock 矩形有任何相交**，
而收起状态机一旦收到 `covered` 就直接 `ForceHide`。于是任何压到 Dock 边缘的小窗口
——桌面歌词、悬浮工具条、截图工具——都会让 Dock 收走。

**处理**：新增 `ForegroundCoverage.IsFullyCovered`（要求窗口矩形完全包含 Dock 矩形），
隐藏判定改用它；`IsCovered` 保留给"被遮挡时禁止热区唤出"那类仍需要"相交"语义的场景。

## 3. 桌面歌词靠近 Dock 导致 Dock 消失

**原因**：SodaMusic 的「桌面歌词」是一个大尺寸置顶窗口（实测 1002×379，把 Dock 矩形完全盖住）。
它与 Dock 同为置顶，后创建的窗口排在后面，于是 Dock 被压住/触发遮挡收起。

**处理**：Dock 不再置顶，歌词窗口在其上方但 Dock 自身保持可见；同时因为不再"碰到就藏"，
歌词窗覆盖 Dock 区域也不会触发收起。

**实测**（真实汽水音乐桌面歌词窗口在前台）：

```
歌词窗 (804,1298)-(1806,1677) 完全覆盖 Dock (1127,1421)-(1432,1540)
Dock 可见 = True，持续 2 秒以上不再消失
```


## 升级说明

覆盖安装即可。此前把 Dock 当成"总在最前"的用法会变化：现在它会被普通窗口盖住，
点 Dock 之前先把窗口挪开或最小化。若你更希望"窗口打开时 Dock 仍浮在最上层"，
这个行为可以在设置里做成开关，说一声我加。
