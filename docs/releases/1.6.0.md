# GlassDesk Plus 1.6.0

最低系统从 Windows 11 21H2 下调到 **Windows 10 版本 2004（Build 19041）**，Windows 10 上自动降级外观，
功能不缺。

## 1. 支持范围

| 系统 | 表现 |
|---|---|
| Windows 11 21H2+ | 完整外观：系统背景材质（Mica）+ DWM 圆角 |
| Windows 10 2004+ | 自绘玻璃 + 自绘圆角；无 Mica 材质，其余功能一致 |
| Windows 10 19040 及以下 | 拒绝启动并提示升级 |

安装包的最低版本同步改为 `10.0.19041`，Windows 10 上可以直接安装。

## 2. 降级是"按能力探测"，不是按版本号猜

`WindowsCapabilities` 原本就把能力拆开判断（系统背景材质、DWM 圆角、深色标题栏），
这次只是把产品门槛从 22000 降到 19041，其余判断原样生效：

```
Build 19045  -> 支持启动；不请求系统背景材质；不请求 DWM 圆角；深色标题栏仍可用
Build 19040  -> 判为不支持
```

窗口玻璃在 Windows 10 上走液态玻璃自绘渲染（桌面采集 + 折射），不依赖任何 Win11 专属接口；
圆角由自绘面板提供。关于页会如实显示当前处于哪种外观。

## 3. 新增：在 Windows 11 上验证 Windows 10 路径

新增诊断参数 `--verify-os-build <构建号>`：把能力探测伪装成指定构建，用来在 Win11 机器上
跑一遍 Windows 10 的降级路径，不必等真机。

```
GlassDesk.exe --verify-os-build 19045 --show-settings
```

关于页实测输出：

```
Windows：10.0.19045（Build 19045）
系统背景材质：不支持，使用自绘面板
窗口圆角：不受支持，使用自绘圆角
窗口玻璃做法：液态玻璃（自绘折射 + 桌面采集）
```

新增验收 `--win10-fallback`（8 项）：构建号边界、能力降级、Dock 窗口可创建显示、
表面模式不是亚克力、向 DWM 递交 Mica/圆角请求时被安全跳过、深色标题栏仍生效。

## 4. 说明

- .NET 10 官方支持矩阵里，Windows 10 仅限 **LTSC / 企业版**（21H2、1809、1607）。
  消费版 Windows 10 22H2 实测可运行（本版即按 19045 的完整降级路径验证过），
  但不在微软官方支持列表内；重要场景建议仍用 Windows 11。
- 没有 Windows 10 真机，本次验证方式是「Win11 上强制降级能力集 + 真实窗口渲染」，
  能证明代码路径在降级能力下不崩、不越权请求，但真实 Win10 的 DWM 行为仍建议实机复测。
