# GlassDesk 1.3.0

- Dock 新增“切换桌面图标显示”入口，与快捷键使用同一显隐动作。
- 设置 → Dock 增加启动台、此电脑、切换桌面图标三个独立开关，即时保存并生效；按上述顺序固定在左侧，隐藏项不占位置。
- 新图标沿用单色圆角描边、主题颜色、悬停放大与整体尺寸倍率。短外框的最小长度与已启用入口数量一致。
- 保留液态玻璃/磨砂玻璃选择、Dock/启动台透明度、Dock 整体大小与外框长度调节。
- 包含 1.2.2 之后的设置安装状态刷新、窗口切换列表整理和后台资源管理改进。
- 更新后的源码快照还修复了外部窗口最大化或还原后，Dock 仍显示旧玻璃背景的问题：共享桌面场景会在窗口最大化状态变化时重建对应的原生视觉。

使用设置 → 关于 → 检查更新，或下载安装包覆盖现有安装。无需删除旧版或 Data；设置、应用库、布局和图标缓存均保留。

公开源码：https://github.com/everlosttime/glassdesk-open-source 。公开 v1.2.2 与 v1.3.0 两个快照，采用 Apache-2.0，保留第三方版权与许可说明。

本机 Windows 11 已验证入口开关、8 种组合、保存/重启、固定顺序、桌面图标显隐、悬停和短外框。安装包为 Windows 11 x64 自包含版本，未签名；高级玻璃采集依赖系统能力与部分非公开接口，未宣称所有 Windows Build、显卡、HDR、多屏环境均已完成现场验证。
