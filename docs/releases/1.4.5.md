# GlassDesk Plus 1.4.5

小组件的刷新频率改为固定值，界面上不再显示频率选择。

## 改动

| 小组件 | 刷新频率 | 说明 |
|---|---|---|
| 时钟 | **1 秒** | 秒针要准，必须每秒刷新 |
| 天气 | **30 分钟** | 数据来自网络，更新本来就慢 |
| 其余（日期 / 系统监控 / 音频 / 备忘录 / 待办 / 日历） | 1 秒 | 本地数据，开销可忽略 |

- 设置 → 小组件 里**不再有「刷新频率」下拉框**，只留每个小组件的开关
- 旧配置里选过的频率（例如天气 5 秒）会在加载时被纠正为固定值
- 刷新频率仍按小组件各自计时，不是所有小组件一起重绘

## 验证

`--widgets-default` 扩到 10 项并全部通过，新增两条：

```
刷新频率为固定值（时钟 1 秒 / 天气 30 分钟） -> 时钟=1000ms、天气=1800000ms、旧配置 5000ms 纠正为 1800000ms
设置界面不再展示刷新频率选择                  -> 四个下拉框全部已移除
```

其余 8 项继续覆盖：默认全关、独立开关互不影响、旧配置迁移、恢复默认等。

## 升级说明

覆盖安装即可。`Data` 保留；旧的 `refreshIntervalMs` 值会被规范化，无需手工改配置。
