# GlassDesk Plus 1.4.3

本版把小组件的默认状态改为关闭，同时保留每个小组件的独立开关。

## 小组件默认关闭

- **总开关「启用小组件」默认关闭**：新安装不再自动往 Dock 上塞一行小组件图标
- **八个小组件各自的开关默认也关闭**：打开总开关后，仍然只有被单独勾选的小组件才会出现
- 已有的 `settings.json` 里存的是显式值，老用户保持原状，不会被重置
- 「恢复当前页默认」会回到「总开关关 + 八个全关」

## 每个小组件的独立开关保持不变

设置 → 小组件 里仍然是：

| 小组件 | 独立开关 | 刷新频率 |
|---|---|---|
| 时钟 / 日期 / 系统监控 | 各自独立 | 1 / 2 / 5 秒 |
| 天气 | 独立（含城市） | 5 / 10 / 30 秒 |
| 音频 / 备忘录 / 待办 / 日历 | 各自独立 | 1 / 2 / 5 秒 |

总开关关闭时这些开关置灰；打开后可逐个勾选，勾选谁就只出现谁。

## 验证

新增可运行验收（真实 `DockWindow` + 临时数据目录）：

```
dotnet run --project tests/GlassDesk.LauncherAcceptance -c Release -- --widgets-default
```

7 项断言：新配置总开关为关、八个小组件全关、默认 Dock 上 0 个小组件图标、
只开总开关仍为 0、单独启用时钟后**只有时钟可见**（8 个视觉里 1 个显示）、
关总开关立即全部收起、恢复默认回到全关。

## 升级说明

覆盖安装即可，无需删除旧版或 Data。旧配置的 `widgetsEnabled` 与各小组件 `enabled`
都是显式持久化的，升级后行为不变；只有全新安装或手动恢复默认时才会是关闭状态。
