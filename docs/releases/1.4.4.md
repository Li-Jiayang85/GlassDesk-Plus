# GlassDesk Plus 1.4.4

修复 1.4.3 里小组件无法独立开关的问题。

## 问题

1.4.3 把小组件默认改为关闭后，总开关关着时**八个独立开关全部被置灰**（`IsEnabled = false`），
用户根本无法逐个打开——看起来像「小组件不能独立开启关闭」。

## 修复

**去掉总开关「启用小组件」**，每个小组件自己的开关就是唯一的控制：

- 设置 → 小组件 里只有八个独立开关，任何时候都可点击
- 勾选谁就只出现谁，彼此互不影响（时钟 + 日期可同时开，关掉时钟不影响日期）
- 小组件默认全部关闭，需要哪个就打开哪个
- 旧配置里的 `widgetsEnabled=false` 会迁移成「八个小组件全部关闭」，字段本身保留、不再起门禁作用
- 「恢复当前页默认」回到全部关闭

## 验证

`--widgets-default` 验收扩到 8 项并全部通过：

```
新配置里八个小组件全部默认关闭                 -> 8 个，开启 0 个
总开关不再起门禁作用（界面已移除）              -> WidgetsEnabled=true（仅字段兼容）
默认状态下 Dock 不显示任何小组件图标            -> 0 个
独立开关只放出被选中的那一个                    -> 8 个视觉里只有 Clock 显示
两个独立开关可同时生效                          -> Clock + Date 同时显示
关掉其中一个不影响另一个                        -> 只剩 Date 显示
旧配置 widgetsEnabled=false 迁移为各开关关闭    -> 字段 true、八个全关
恢复默认后回到全部关闭                          -> 开启 0 个
```

另外用 UI Automation 实测：八个复选框 `可操作=True`、勾选状态可正常切换并立即写入
`settings.json`（勾选时钟后 `clock.enabled=true`，取消后回到 0 个启用）。

## 升级说明

覆盖安装即可。`Data` 与既有小组件设置保留；`widgetsEnabled` 字段不再显示在界面上。
