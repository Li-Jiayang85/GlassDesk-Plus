# GlassDesk Plus 1.4.2

本版补齐 Dock 自带入口的显示开关，并移除 1.4.1 里方向做错的「托盘图标」设置。

## 移除：托盘图标自定义

1.4.0/1.4.1 新增的 **设置 → 托盘图标** 小节（通知区域图标的选择与显示开关）是对需求的误读：
真正要的是 Dock 自带图标的显示控制，不是通知区域图标。该小节连同 `TraySettings`、
自定义图标渲染与相关测试一并删除。

- 通知区域图标**依然存在**，仍是内置品牌标识，行为与 1.4.0 之前一致
- 旧 `settings.json` 里残留的 `tray` 字段会被忽略，无需手工清理

## 新增：设置里可以控制 Dock 上的全部自带图标

Dock 左侧那一排自带入口原本只有三个能隐藏，**「设置」（齿轮）永远显示**。现在四个都能单独控制：

| 设置项（设置 → Dock → 左侧固定图标） | 默认 |
|---|---|
| 显示启动台 | 开 |
| 显示此电脑 | 开 |
| 显示切换桌面图标 | 开 |
| **显示设置**（新增） | **开** |

- 顺序固定为 启动台 → 此电脑 → 切换桌面图标 → 设置，隐藏的**不占位置**，后面的入口左移补齐
- 改动即时生效并写入 `settings.json` 的 `dock.showSettingsEntry`
- 四个全部隐藏也正常，Dock 只是没有固定入口，应用图标照常显示

## 顺带修掉一处宽度计算

齿轮原先「一直显示但不计入宽度」：固定外框设得较短时，磁贴条的计算可用宽度会比实际多出一个入口（56 DIP），可能压到齿轮上。现在按实际显示的入口数量统计（最多 4 个），短外框下不再重叠。

## 验证

新增可运行的验收用例（真实 `DockWindow` + `SettingsWindow`，临时数据目录）：

```
dotnet run --project tests/GlassDesk.LauncherAcceptance -c Release -- --dock-entries
```

7 项断言，覆盖：四个开关都在设置里、齿轮与其余入口同排、**16 种组合**即刻生效且无空隙、
单独隐藏齿轮后不留空位、写入 `settings.json`、重载后回显、全部隐藏不报错。

同时把既有测试从 3 个入口 / 8 种组合扩到 4 个入口 / 16 种组合：
`tests/GlassDesk.Dock.Tests/DockBuiltinEntrySettingsTests.cs` 与
`tests/GlassDesk.LauncherAcceptance/DockBuiltinEntryCases.cs`。

## 升级说明

覆盖安装即可，无需删除旧版或 Data。新增的 `dock.showSettingsEntry` 缺省为 `true`，
旧配置文件无需迁移（齿轮照旧显示）。
