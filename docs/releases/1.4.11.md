# GlassDesk Plus 1.4.11

本版只修发布流程与文档，程序行为与 1.4.10 完全一致。

## 修复：release 说明被写成一串哈希表文本

此前每个 release 的说明在 GitHub 上都显示成 `{"value" => "# GlassDesk Plus …", "PSPath" => …}`，
而不是正常的 Markdown。

**原因**：`build/release.ps1` 直接把 `Get-Content -Raw` 的返回值塞进 `ConvertTo-Json`。
PowerShell 5.1 里它带 ETS 属性（`PSPath`、`PSParentPath`、`ReadCount`…），
`ConvertTo-Json` 会把它当对象序列化，`body` 于是变成 `{"value": …}`。

**修复**：显式 `[string]` 转换后再序列化。

**已修复的历史 release**：v1.0.5、v1.4.0 – v1.4.10，共 12 个，现均以正常 Markdown 显示。
