# GlassDesk Plus 1.5.0

对齐上游 1.3.2 – 1.4.4 的公开改进，挑出三件对日常使用影响最直接的做进本分支。

## 1. Dock 显示方式：常驻显示 / 自动隐藏

设置 → Dock 新增「显示方式」。

- **常驻显示**（默认）：与之前一致，Dock 一直可见
- **自动隐藏**：鼠标离开后约 0.3 秒收起；移到 Dock 原位置即可唤出
- 右键菜单、拖动图标、启动台打开期间保持显示，不会中途消失
- 切换立即保存并生效，重启后保留

这是上游 1.3.3 的能力。本分支此前虽然保留了自动隐藏的状态机，但正常模式下从未接入，
设置里也没有入口；这次补齐了状态机的普通分支与边缘唤出。

## 2. 再次点击已在前台的应用 → 最小化

在 Dock 里点击一个**当前已经在前台**的应用图标，现在会把它的窗口最小化，而不是原样再提一次
（后者看起来像「点了没反应」）。再点一次即还原并回到前台。

- 只处理「该应用只有一个窗口且确实在前台」的情况
- 后台窗口、多窗口、目标失效的条目行为完全不变
- 与上游 1.3.3 的行为一致

## 3. 启动台：从桌面批量添加

启动台「添加应用」菜单新增 **「从桌面批量添加…」**（上游 1.3.6）。

- 同时读取个人桌面与公共桌面，分组显示
- 默认全选，支持全选 / 清空，弹窗内直接勾选
- 只读桌面第一层，跳过隐藏与系统项；重名项目在标题提示里带完整路径
- 导入后与「从文件夹批量添加」走同一套流程，重复项自动去重

## 未跟进的上游改动

| 上游版本 | 内容 | 说明 |
|---|---|---|
| 1.3.5 | 无扩展名图标资源（ProductIcon）兼容、失效图标回退 | 需要重写图标提取链路，留待下一版 |
| 1.4.0 | 启动台文件夹（拖拽 500ms 合成） | 本分支已有分组机制，交互形态不同，暂不替换 |
| 1.4.4 | 液态玻璃信息栏、控制中心、网盘下载 | 前者是较大的新模块；后者与本分支的 GitHub 直链更新模型冲突 |

滚动翻页默认（向下 = 下一页）本分支早已与上游 1.3.2 一致，无需改动。

## 升级说明

覆盖安装即可，设置与布局保留。Dock 默认仍是常驻显示，升级后外观不变；
想要更清爽可以在设置 → Dock 里切成自动隐藏。
