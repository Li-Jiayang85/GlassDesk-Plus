# 赞助收款码

这里放的是项目所有者本人的收款码，均为方形裁切后的二维码（保留四周扫描留白，不重新绘制、不二次编码）：

- `alipay.jpg`：支付宝收款码（也兼容 `alipay.png`）。
- `wechat.png`：微信收款码。

图片作为 Settings 组件的嵌入资源随软件发布。设置页只显示支付方式选择和“赞助”按钮；点击按钮后，独立弹窗才展示所选渠道的收款码。缺少或无法读取时，弹窗显示该渠道暂未开放，不展示其它渠道的二维码，不影响免费功能。

弹窗里的二维码区域是 260×260 的正方形白底框，`Image` 使用 `Stretch="Uniform"`，因此素材本身做成正方形、四周留白约占 6%，扫出来最稳；换图时保持这个比例即可，不需要改代码。注意文件扩展名要和真实编码一致（PNG 就叫 `.png`，JPEG 就叫 `.jpg`）。

赞助者在手机支付应用内填写任意金额。软件不创建支付订单、不判断到账情况；付款结果以支付宝或微信为准。
